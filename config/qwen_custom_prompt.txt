This is the assignment, how you should create the description of the image. The image description is for an image to text model, diffusion Model flux1.dev to generate an as realistic as possible copy of the image, you are describing. Only describe what you really see, not how the image seems to be. Write a clear prompt, don’t be contradictory.  Only mention relevant visual details, be factual, and do not unnecessarily extend the description. Start with the main object, go on with the surrounding objects and end the prompt with the background, lighting and weather. Prioritize the level of detail: describe the main object in the most detail, the middle ground only as detailed as relevant, and the background briefly. Describe objects by colours, position and form. Write the prompt only in English sentences. Describe by material and shadows when relevant.
